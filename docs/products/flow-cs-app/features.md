## 1. 한눈에 보기

처음 이 제품에 로그인한 상담사라면 머리의 소프트폰 툴바에서 [CTI 로그인]을 누르고 [대기]를 누르는 것으로 하루를 시작한다. 그 아래 홈 탭에 통합상담이 떠 있고, 전화가 들어오면 고객정보 카드가 번호로 고객을 찾아 세우고 상담 상세 폼이 열린다. 통화가 끝나면 상담유형과 문의내용을 적어 [상담 저장]을 누른다. 이 한 바퀴가 제품의 중심이고, 나머지 화면은 모두 이 바퀴에 바퀴살처럼 붙어 있다.

쓰는 사람은 넷으로 나뉜다. 상담사는 통합상담 하나로 하루를 보낸다. 운영 관리자는 상담이력 관리·콜백 관리·VOC 관리·캠페인 관리에서 일을 배분하고 결과를 본다. QA 담당은 평가 관리에서 평가표를 짜고 계획을 돌려 상담 품질을 매긴다. 교육 담당은 시험·교육 관리에서 문항과 시험지를 만들고 시험을 연다. 그리고 시스템 관리자가 사용자·조직·권한·메뉴·코드·시스템변수를 손본다.

채널은 전화·채팅·이메일 셋이다. 전화는 iPRON CTI에 붙은 소프트폰이 받고, 채팅은 상담 중계 서버의 상담사 위젯이 통합상담 안으로 들어오며, 이메일은 같은 중계를 거쳐 메일 세션으로 들어온다. 채팅과 이메일은 시스템변수 `채팅 기능 사용`·`이메일 상담 사용`으로 고객사마다 켜고 끈다. 접촉 방향은 인바운드·아웃바운드·수기 셋으로 기록된다.

한 통화가 가는 길은 이렇다. 인입 팝업에서 [받기]를 누르면 상담 세션 카드가 하나 생기고, 고객정보 카드가 전화번호로 고객을 찾는다. 통화 중에는 가운데 실시간 대화 칸에 자막이 흐르고 오른쪽 레일의 AI Advisor가 요약과 추천을 낸다. 상담사는 상담 상세에 상담유형·문의내용·키워드를 적고, 재통화가 필요하면 [예약]을, 민원이면 후속조치를 켠다. 저장된 상담은 상담이력 관리에 쌓이고, 평가계획이 그중 일부를 골라 평가하고, 통계 화면이 상담유형별·상담사별로 집계한다.

## 2. 상담사 작업대, 통합상담

통합상담은 세 열이다. 왼쪽에 고객정보 카드와 상담이력 카드, 가운데에 상담 세션 막대와 실시간 대화와 상담 상세, 오른쪽에 접었다 펼 수 있는 레일이 있다. 머리에는 소프트폰 툴바와 함께 [업무지원]·[지식베이스]·알림·쪽지·채팅 단추가 늘어선다. [업무지원]을 누르면 원격지원과 사이트 바로가기가 나오고, 사이트 바로가기의 목록은 사이트링크 관리에서 관리자가 적어 둔 것이다.

### 소프트폰 툴바

전화 툴바는 [CTI 로그인]·[대기]·[걸기]·[끊기]·[보류]·[호전환]·[이석] 일곱 단추와 상태 표시로 이루어진다. [이석]은 교육·공무·식사 중 하나를 사유로 고른다. 전화가 오면 콜 인입 팝업이 떠 [받기]와 [거절]을 묻고, [걸기]는 내선·외선을 골라 번호를 넣는 팝업을 연다. [호전환]은 협의 전화·즉시호전환·3자 통화·재연결을 한 팝업에서 다룬다. 협의 호전환은 내선번호에만 허락되며, 외선으로 걸 때 앞에 붙이는 번호와 내선으로 볼 자릿수는 시스템변수 `[공통] 외선 발신 접두번호`·`[공통] 내선번호 최대 자릿수`가 정한다.

소프트폰은 두 가지 방식 중 하나로 CTI에 붙는다. 시스템변수 `소프트폰 유형`이 `ICAPI`면 기존 HTTP 방식으로 CTI 명령만 주고받고 음성은 물리 IP폰이 낸다. `WEBSOCKET`이면 WebSocket으로 CTI에 붙고, `[SIP] 사용 여부`를 켜면 브라우저가 마이크로 직접 통화하는 SIP/WebRTC 음성이 더해진다. 두 방식의 단추와 동작은 같다. 상담사가 보는 차이는 WebSocket 방식에서 첫 로그인 때 마이크 권한을 묻는 것 하나다.

채팅과 이메일에도 각자 툴바가 있다. 채팅 툴바는 [채팅 로그인]·[채팅대기]·[채팅이석], 메일 툴바는 [메일 로그인]·[메일대기]·[메일이석]이다. 이석 사유는 전화와 같은 목록이다. 채팅 로그아웃을 누르면 진행 중인 대화가 끝날 때까지 단추가 "자동 종료 대기"로 바뀌어 기다린다.

### 고객정보와 상담이력

고객정보 카드는 통화가 붙으면 전화번호로 고객을 찾아 고객명·전화번호·회사명을 세운다. 없는 번호면 미등록고객으로 두고 상담 상세에서 바로 적을 수 있다. 카드의 [SMS 발송]은 문자템플릿 관리에 등록된 템플릿을 골라 변수를 채우고 보내는 팝업이다.

상담이력 카드는 VOC·상담·SMS 세 탭이다. 상담 탭은 이 고객의 최근 상담을 보여 주고 고객명이나 전화번호로 다시 [조회]할 수 있다. 한 건을 열면 상담이력 상세 팝업에 상담유형·상담 내용·AI 상담 요약·통화시간·후속조치·재통화예약·캠페인 명이 함께 뜬다. VOC 탭은 이 고객 번호로 열린 VOC를 보여 주고, 지금 상담을 그 건에 연결하거나 해제한다. SMS 탭은 이 번호로 보낸 문자 이력이다.

### 상담 세션과 상담 상세

가운데 맨 위의 상담 세션 막대는 채널별 카드다. 전화는 통화 하나가 카드 하나이고, 채팅은 "챗" 표지의 채팅상담 카드가 고객 이름과 시작 시각을 달고 서며, 메일은 "메일" 표지의 메일상담 카드가 미회신·회신완료 상태와 제목을 단다. 카드를 누르면 아래 상담 상세가 그 세션의 폼으로 바뀐다. 세션이 없으면 "진행 중인 상담 세션이 없습니다"가 보인다.

상담 상세는 상담 정보 폼이다. 고객명·전화번호·고객아이디·상담구분·문의내용·추출 키워드·AI 상담 요약·통화연결·후속조치가 한 폼에 있고, 상담유형은 검색 칸에서 이름으로 찾는다. 단추는 [임시 저장]·[상담 저장]·[예약] 셋이다. [예약]은 두시간뒤·오후 한시·내일 같은시각·직접입력 중에서 재통화 시각을 고르며, 후속조치를 켜고 저장하면 후속 VOC를 등록할지 묻는다. 채팅 세션에서는 폼 왼쪽이 대화 창이 되고 [전송]으로 답한다.

### 실시간 대화와 금지어

통화 중에는 상담 상세 옆 실시간 대화 칸에 고객과 상담사의 말이 말풍선으로 흐른다. 서버가 STT 결과를 상담사의 내선 주소로 보내 주기 때문에 다른 상담사의 자막은 섞이지 않는다. 상담사 말풍선 아래에는 "금지어 감지: …"가 붙을 수 있다. 금지어 관리에 등록된 대표 금지어·변형어·예외어와 맞춰 본 결과이고, 부분 포함은 세지 않는다. 후처리가 끝나면 그 통화의 자막은 사라진다.

### 브리핑, 대기 현황, 콜봇 배너

상담 상세 위에는 접고 펼 수 있는 상담 지원 브리핑이 있다. 우선 확인·응대 포인트·리스크 메모·다음 액션 같은 항목으로 통화 전후에 챙길 것을 보여 준다. 상담 대기 현황 카드는 전화·채팅·이메일 채널별로 기다리는 건수를 한 줄씩 보여 준다. 직전 콜봇 대화 배너는 이 통화가 콜봇을 거쳐 왔을 때 그 대화를 요약해 띄우고 [전체보기]로 전문을 연다.

### 오른쪽 레일

레일은 세로 탭 다섯이다. 패널마다 통화와 무관한 "내 업무함"으로도 쓸 수 있어, 전화가 없는 시간에 VOC를 처리하거나 평가를 끝낼 수 있다.

| 탭 | 보여 주는 것 | 상담사가 하는 일 |
|---|---|---|
| AI Advisor | AI 상담 요약, 상담유형 추천, 권장 응대 문장과 히스토리, 의도 분석(신뢰도), 감정 분석(긍정·중립·부정, 평균 점수), 키워드, 추천 답변 가이드와 출처 기반 안내 | 요약 복사, 응대 문장 복사, 추천 상담유형을 폼에 적용, 출처 문서를 지식베이스 검색으로 열기 |
| 캠페인 | 할당된 캠페인 대상, 스크립트·인사말·유의사항, 설문 정보 | [발신], 설문 [응답 저장], 메모, 재통화 예약시간, [완료] |
| 평가 | 상담 평가: 내게 배정된 평가 대상(전체·미완료·완료) | 인라인 평가표에 점수와 의견을 적어 저장 |
| 시험 | 시험 상태: 배정된 시험 일정, 마감 임박, 응시 완료 | 시험 대기 → 응시 → 결과 확인 |
| VOC | 내 담당 VOC(진행중·종료), VOC 정보와 활동 이력 | 메모 등록, 이관, 종료 |

### 지식베이스 검색

머리의 [지식베이스]는 창 위에 떠 있는 지식베이스 검색 패널을 연다. 추천 목록 탭은 지금 통화의 키워드로 고른 문서를 카드로 보여 주고, 직접 검색 탭은 키워드·하이브리드·AI 검색 세 방법으로 찾는다. 결과 한 줄을 누르면 문서 본문과 첨부가 패널 안에서 열린다. 패널은 상담 화면을 가리지 않아 통화 중에 열어 둔 채로 일할 수 있다. AI Advisor 레일의 출처 안내도 같은 패널을 연다.

## 3. 고객·민원·업무

상담이 끝나면 일은 세 갈래로 흩어진다. 고객 자체를 손보는 일, 민원을 끝까지 따라가는 일, 다른 사람에게 넘기는 일이다. 업무 관리 메뉴가 이 셋을 모아 둔다.

고객정보 관리는 고객 목록에 고객명·전화번호·회사명·사업여부·비고를 두고 [등록]·[삭제]한다. 회사명은 [업체조회]로 찾아 채운다. 악성민원 관리는 주의가 필요한 고객을 전화번호로 등록하고 경고 횟수·최근 경고 일자·최근 경고 사유·악성민원 메모를 남기는 화면이다. 목록에서 한 줄을 고르면 상세가 옆으로 열려 메모를 이어 쓴다.

VOC 관리는 민원 한 건의 수명을 다룬다. VOC 목록에서 VOC번호·상태·담당자·문의내용·해결내용을 보고, 상세에서 메모를 쌓고 [이관]으로 담당자를 바꾸고 [회수]로 되돌리고 [종료 처리]로 닫는다. 상태 변화와 메모는 활동 이력 타임라인에 남는다. 상담이력 상세의 [VOC 연결]은 상담 한 건을 VOC에 묶고, 통합상담에서 후속조치를 켜고 저장하면 후속 VOC가 바로 만들어진다.

콜백 관리는 IVR이나 챗봇이 받아 둔 전화 요청을 상담사에게 나눈다. 콜백 목록에 콜백번호·인입경로·수신번호·대표번호·서비스·처리상태가 있고, [수동분배]로 고른 건을 상담원에게 주거나 [자동분배 설정]에서 대표번호별 대상 그룹을 정해 자동으로 나눈다. 처리상태는 미처리·처리중·처리완료 셋이다. 예약콜 관리는 통합상담의 [예약]과 캠페인 재통화가 만든 예약을 모아 예약일시·상태(예약·완료·만료·취소)·출처(일반상담·신규 캠페인)로 보여 주고 [완료 처리]·[취소]한다. 외부이관 관리는 외부 조직으로 넘긴 건을 티켓번호·담당자·처리상태·이관내용으로 추적한다.

상담이력 관리는 저장된 모든 상담의 장부다. 상담번호·채널유형·상담유형·처리상태·담당자로 조회하고, 한 건을 열면 [저장]·[이관]·[이력보기]·[녹취청취]·[평가진행]·[VOC 연결]이 있다. [이관]으로 다른 상담사에게 넘기면 받은 사람에게 티켓이관 알림이 가고, [녹취청취]는 웹 재생기 연동이 설정된 고객사에서 녹음을 연다. 티켓은 상담 티켓·캠페인 티켓·콜백 티켓 셋으로 나뉘고 처리상태는 미처리·처리중·처리완료로 흐른다. 발행일자 기간을 두고 조회하면 엑셀로 내릴 수 있다.

사람 사이의 연락은 넷이다. 쪽지 관리는 보낸사람·받는사람·조회여부가 있는 쪽지 목록이고 [쪽지 보내기]·[답장]을 한다. 알림 관리는 티켓·공지·쪽지·요청·콜백·평가·예약콜·금지어·캠페인·Advisor·VOC 구분으로 들어온 알림을 모아 두며 머리의 알림 단추가 같은 것을 보여 준다. 공지사항은 관리자가 쓰고 모두가 읽는 글이고, 게시판은 카테고리를 나눠 글을 올리고 댓글을 달며 조회수가 센다. 머리의 채팅 단추로 상담사끼리 채팅방을 만들고 초대하는 내부 채팅도 있다.

## 4. 캠페인(아웃바운드)

캠페인은 걸려 오는 전화가 아니라 걸어야 할 전화의 목록이다. 이 영역은 Vue 판에만 있고 React 판에는 옮기지 않기로 했다(8장). 메뉴는 캠페인 관리와 신규 캠페인 관리 두 묶음이 있다.

캠페인 관리 묶음은 캠페인 관리·대상자 관리·캠페인 할당·설문조사 관리·설문 문항 관리·설문응답 관리·캠페인 진행 현황 일곱 화면이다. 캠페인 관리에서 캠페인명·유형·기간을 만들고 상태를 계획중·준비 완료·활성·일시 중지·완료·보관으로 옮긴다. 대상자 관리는 엑셀로 대상자를 올리는 곳이다. [템플릿 다운로드]로 양식을 받아 채우고 [엑셀 업로드]하면 오류 건수가 집계되고 [오류 다운로드]로 틀린 줄만 받는다. 캠페인 할당은 올린 대상자를 상담원에게 [대상자 자동할당]·[대상자 수동할당]으로 나눈다. 대상자 상태는 신규에서 할당됨·진행중·연락 시도 중·연락 성공·재연락 예정·연락 불가·거절·완료·실패·제외됨까지 열두 단계다.

상담사 쪽에서는 통합상담 레일의 캠페인 탭이 할당된 대상을 보여 주고, [발신]으로 걸어 스크립트를 읽고 설문에 [응답 저장]하고 [완료]한다. 받지 않으면 재통화 예약시간을 잡아 예약콜 관리로 보낸다. 관리자는 캠페인 진행 현황에서 진행현황·상담원별 현황·일별 처리 현황·진행률 추이·설문결과 다섯 탭으로 지켜본다. 설문 결과 화면은 문항별 결과와 기준 문항·비교 문항을 잡는 교차 분석, [결과 내보내기]를 갖는다.

신규 캠페인 관리 묶음은 2026년 4월 설계로 다시 짠 판이다. 신규 캠페인 관리는 캠페인 하나를 기본정보·대상자·할당 탭이 있는 작업 공간으로 다루고, 대상자 열을 캠페인마다 다르게 정의한다. 신규 대상자 관리는 대상자 그룹 단위로 엑셀 컬럼을 저장 필드명에 맞추어 올리거나, 외부 DB에 수집 설정을 걸어 [스케줄 시작]·[즉시 실행]으로 끌어온다. 신규 설문 관리와 신규 스크립트 관리는 캠페인에 붙일 설문 문항과 스크립트를 따로 두고, 신규 캠페인 현황은 캠페인 상태와 대상자 상태(신규·할당됨·진행중·완료·재통화 예약)를 한 표로 본다. 두 묶음이 함께 메뉴에 있으므로 어느 쪽을 운영에 쓸지는 고객사가 정한다.

## 5. 품질·교육

### 평가

평가는 상담 한 건을 단위로 한다. 티켓이 아니라 저장된 상담이력 하나에 점수를 매기고, 평가표 문항 템플릿 관리 → 평가표 관리 → 평가계획 관리 → 평가 결과 관리 → 평가통계 순서로 메뉴가 놓인다.

평가표 문항 템플릿 관리는 문항의 표준 창고다. 문항명·문항분류·배점을 적고 채점방식을 고른다. AI 맥락 평가는 AI가 발화를 읽어 점수를 내고 키워드를 적으면 그 주변만 읽어 비용을 줄이며, 키워드 확인은 키워드가 나오면 만점이고 없으면 0점, 금지어 검출은 금지어가 나오면 불합격이다. 뒤의 둘은 AI를 부르지 않는다. 평가표 관리는 이 문항을 [템플릿에서 가져오기]나 [직접 추가]로 모아 평가표명·평가표유형·합격선(/100)을 정한다. 가중치는 배점 비율·균등·수동 셋 중 하나고, 결과가 하나라도 생기면 평가표는 잠긴다. [복제]로 새 판을 만든다.

평가계획 관리가 평가를 실제로 돌린다. 계획명과 평가표를 정하고 상담기간·채널·통화시간·상담사당 최대 건수로 [대상 수집]을 하면 대상 목록이 만들어진다. [배분]은 평가자들에게 균등 또는 랜덤으로 나누고, [평가 시작]·[일시중지]·[재개]·[완료]로 상태를 옮긴다. AI 평가는 [AI 평가 모델 선택]으로 모델을 고르고 [주기 설정]으로 실행 주기와 1회 처리 건수를 정하며, 실패한 건은 [AI 실패 재실행]으로 다시 돈다. 평가자는 통합상담 레일의 평가 탭에서 자기 몫을 인라인 평가표로 끝내고, 상담이력 상세의 [평가진행]으로 계획 없는 단건 평가도 할 수 있다.

평가 결과 관리는 건별 평가결과와 항목별 득점률·평가 의견을 보여 주고, AI 결과는 AI상태와 실패사유를 함께 단다. AI 점수를 사람이 고치면 원본과 수정 사유가 같이 남는다. 미달자에게는 [보충시험 생성]으로 시험을 붙인다. 평가통계는 평가계획별·상담사별·평가자별 채점 현황과 점수 분포·합격률·항목별 강약점·기간별 추이를 그리고, 계획을 셋까지 골라 [계획 비교]한다.

### 시험·교육

시험·교육 관리는 시험·교육 자료 관리와 시험·교육 계획 관리 두 화면이 운영 진입점이다. 자료 관리는 문항·시험지·콘텐츠·외부 생성 검토 네 탭이다. 문항은 손으로 만들거나 [대량 업로드]로 올리고, 시험지는 문항을 모아 만들며, 콘텐츠는 동영상과 문서를 올려 완독·시청 조건을 건다. 외부 생성 검토는 외부 시스템이 신청한 문항·시험지 후보를 관리자가 승인하는 탭이다. 이 영역도 Vue 판에만 있다(8장).

계획 관리는 칸반이다. 준비·진행·채점 준비·채점/이의제기·마감 다섯 줄에 시험 카드가 놓이고, [시험 생성] 마법사가 유형 선택 → 기본정보 → 콘텐츠 구성 → 운영정책 → 대상자/채점자 → 검토 순으로 새 시험을 만든다. 운영정책은 문항 순서(응시자별 랜덤·시험지 순서대로)와 이동(자유 이동·순차 풀이)과 결과 공개 시점(채점완료 즉시 공개·최종마감 후 공개·수동 공개)이다. 카드 상세는 기본정보·문항 스냅샷·대상자·진행현황·채점·이의제기 탭으로 열린다.

응시자는 통합상담 레일의 시험 탭에서 배정된 시험을 보고 대기 화면을 지나 응시하고 제출한다. 결과가 공개되면 같은 자리에서 점수를 보고 문항 또는 시험 전체에 이의제기를 넣는다. 채점자는 서술형 답안에 점수와 코멘트를 달고 이의제기를 처리한다. 결과를 모아 보는 시험 통계(진행현황·채점·이의제기·진행이력·결과보고서)와 옛 메뉴들은 기본 데이터에서 `usable: false`로 숨겨져 있어 고객사가 메뉴 관리에서 켠다.

### 통계와 상담 현황

티켓 통계 메뉴는 여섯 화면이다. 상담유형별과 상담사별 두 축에 일별·월별·기간별 세 단위를 곱한 것으로, 이름이 그대로 상담유형별 일별 상담통계부터 상담사별 기간별 상담통계까지다. 열은 상담건수·인바운드·아웃바운드·전화·채팅·이메일·평균 통화시간·평균 후처리시간·FCR율이고 조직(대·중·소)과 상담유형(대·중·소)으로 걸러 본다.

상담 현황은 AI 분석 결과로 만든 대시보드다. 실시간현황 모드는 오늘 하루를 보며 새 상담이 적재될 때마다 스스로 갱신하고, 기간조회 모드는 시작일과 종료일을 잡는다. 의도·감정·키워드·지식문서·이상징후 다섯 카테고리의 상위 순위와 상담 키워드 워드클라우드, 감정 분포 차트가 보이고, 이상징후 추적 패널은 금지어가 감지된 상담을 타임라인으로 보여 주며 그 자리에서 상담사에게 [쪽지보내기]를 할 수 있다. 상세 현황 목록에서 한 건을 열면 상담정보와 AI데이터, 추천 문서를 함께 본다.

## 6. 지식·AI

AI는 이 제품에서 따로 선 기능이 아니라 상담 흐름의 곳곳에 끼어 있다. 자막을 만들고, 요약하고, 문서를 추천하고, 평가하고, 금지어 변형을 제안한다. 모두 외부 AI Advisor 서버가 하고 상담 AP는 받아서 보여 준다. 연결은 시스템변수 `AI Advisor 설정` 묶음의 URL·계정·`Advisor(AI) 기능 사용`으로 정하며, 끄면 관련 패널이 조용해지고 나머지 상담 기능은 그대로 돈다.

KMS 관리 메뉴는 통합검색·콘텐츠 목록·카테고리 관리·콘텐츠 승인 관리 넷이다. 두 가지 모양이 있다. 하나는 `AI Advisor KMS URL`이 가리키는 Advisor의 지식관리 화면을 별도 창으로 여는 것이고, 다른 하나는 상담 AP 안에서 문서를 쓰고 승인하는 내장 화면이다. 내장 화면은 문서 작성·초안저장·승인요청과 승인자의 승인 보드, 내 작업함, 대시보드(전체 문서·총 조회수·인기 문서·월별 트렌드·문서 유형 분포)를 갖는다. 승인 상태가 된 문서가 지식베이스 검색의 대상이다. 어느 모양을 쓸지는 고객사 설정이다.

AI Advisor의 실시간 어시스트는 통화 중에 레일의 AI Advisor 탭을 채운다. 요약·권장 응대 문장·의도·감정·지식 추천 다섯 묶음이 서버에서 내선별로 중계되어 오고, 통화가 끝나면 AI 상담 요약과 상담유형 추천·키워드가 따라온다. 상담사마다 Advisor 계정이 있어야 하므로 사용자 관리의 [Advisor 수동 연동]과 연동 관리 화면(연동 Job 목록·Job 상태·에러 메시지)이 그 계정 만들기를 돌본다.

채팅과 이메일은 상담 중계 서버가 고객과 상담사를 잇는다. 고객 사이트의 위젯이 중계 서버에 붙고, 상담 AP의 상담사 위젯이 통합상담 상담 상세 왼쪽 칸에 들어와 같은 대화를 보여 준다. 상담사는 중계 서버에 미리 등록된 채팅 아이디로 매칭된다. 메일은 메일상담 세션 카드로 들어오고, 회신 창에서 회신 본문·참조·숨은 참조·파일 첨부·서명을 다루며 AI 개요 칸이 받은 메일의 요지를 보여 준다. 회신이 필요 없는 메일은 [미회신완료]로 사유를 적어 닫는다.

STT는 두 자리에 있다. 하나는 2장의 실시간 대화이고, 다른 하나는 끝난 통화의 대화를 다시 보는 STT 채팅내역 화면이다. 상담 인텔리전스 API는 상담 한 건에 키워드·의도·감정·지식 추천과 금지어 이상징후를 붙여 적재하는 통로이며, 5장의 상담 현황이 이 데이터를 읽는다. 금지어 정의는 금지어 관리에 있고 API는 이미 있는 정의만 가리킨다.

## 7. 관리

시스템 설정 메뉴는 열 화면이다. 사용자 관리·코드 관리·권한 관리·조직 관리·메뉴 관리·시스템변수 관리·금지어 관리·접속로그 관리·사이트링크 관리·SAP 인터페이스 관리이고, 업무 관리 아래 문자템플릿 관리와 머리의 프로필 관리가 더 있다.

사용자 관리는 아이디·사용자명·조직·사용여부·잠김을 다루고, 상담사라면 내선번호와 CTI 아이디·비밀번호, SIP를 쓰는 고객사면 SIP 아이디·비밀번호까지 적는다. [비밀번호 초기화]와 로그인 화면의 [초기화 요청]이 짝이고, 로그인 실패가 `로그인 보안`의 횟수를 넘겨 잠긴 계정은 관리자가 여기서 푼다. 조직 관리는 조직(대)·조직(중)·조직(소) 세 단이다. 권한 관리는 권한그룹마다 메뉴 권한과 기능 권한을 체크하고 사용자를 넣으며 [복사]로 비슷한 그룹을 만든다. 메뉴 관리는 메뉴명·메뉴코드·상위메뉴·액션타입·순서와 퀵메뉴 사용여부를, 코드 관리는 상위코드 아래 코드·코드명·순서를 편집하는 트리 그리드다.

시스템변수 관리는 묶음별로 값을 고치는 화면이다. 상담사 화면의 모양을 바꾸는 값은 `UI 설정` 묶음에 있고, 같은 화면의 [브랜드 설정]은 브랜드명·로그인 로고·헤더 로고·메인 컬러·서브 컬러와 테마(메인 라이트·웜그레이 라이트·웜그레이 다크)를 한 벌로 등록해 [적용]·[해제]한다. 로그인 화면의 로고와 머리의 로고가 이 설정을 따른다.

| 묶음 | 정하는 것 |
|---|---|
| 로그인 유효 기간 | 기본 로그인 유효시간, 로그인 연장시간, 최대 로그인 유효시간 |
| 로그인 보안 | 로그인 잠금 실패 횟수, 로그인 잠금 시간 |
| CTI 서버 정보 | CTI 서버의 이름·프로토콜·주 서버와 대기 서버 |
| 소프트폰 설정 | 소프트폰 유형, [CTI] WebSocket 서버, [SIP]·[TURN] 값, [공통] 외선 발신 접두번호와 내선번호 최대 자릿수 |
| 웹 재생기 청취 연동 정보 | 녹취 재생기 서버 |
| AI Advisor 설정 | AI Advisor URL, AI Advisor KMS URL, 계정, Advisor(AI) 기능 사용 |
| UI 설정 | 상담메인 UI 버전, 채팅 기능 사용, 이메일 상담 사용 |
| SAP SOAP 연동 | SAP 호출 환경, SAP PI 계정 |

금지어 관리는 대표 금지어 하나에 변형어와 예외어를 각 열 개까지 달고 사용여부를 둔다. [추천받기]를 누르면 AI가 변형어와 예외어를 제안해 목록 끝에 붙이고 새로 들어온 항목만 색으로 표시한다. 화면 위의 금지어 탐지 설정 토글이 감지 자체를 켜고 끈다. 접속로그 관리는 사용자·접속 IP·접속유형(로그인·로그아웃·로그인 연장)·접속일시를 날짜로 조회한다. 사이트링크 관리는 링크명·링크Url·사용여부를 적는 목록이고 머리 [업무지원]의 사이트 바로가기가 된다.

문자템플릿 관리는 템플릿명·메시지유형·메시지 내용을 편집하고 변수를 [삽입]해 두면 보낼 때 채우게 한다. 휴대폰 모양 미리보기가 옆에 있고 [문자발송]으로 바로 보낼 수도 있다. SAP 인터페이스 관리는 WSDL 파일을 [WSDL 업로드]해 인터페이스를 등록하고 [버전 차이]로 바뀐 필드를 보며, [화면 정의]에서 요청 필드와 응답 목록 요소를 골라 조회 화면을 만든다. [미리보기]와 [실제 호출]로 확인한 뒤 [저장 후 메뉴 등록]을 누르면 SAP 연동 메뉴 아래 그 화면이 바로 생긴다. 코드를 고치지 않고 SAP 조회 화면을 늘리는 길이다. 프로필 관리는 각 사용자가 비밀번호 변경·단축키·다크 모드·advisor연동을 스스로 바꾸는 곳이다.
